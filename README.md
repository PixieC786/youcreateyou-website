# You Create You — Website

The official marketing website for [youcreateyou.life](https://youcreateyou.life) — a consciousness and personal transformation platform.

Built with **Next.js** · **TypeScript** · **Tailwind CSS** · Deployed on **Vercel**

---

## What is You Create You?

You Create You is a complete transformation ecosystem:

- **The App** — 20 tools across 4 phases of inner work (app.youcreateyou.life)
- **The Book** — the foundational text for the YCY journey
- **The Website** — this repo — the front door to the world

---

## The 4 Transformation Phases

| Phase | Name | Focus |
|---|---|---|
| 01 | See Clearly | Awareness, patterns, frequency |
| 02 | Release & Discover | Fear, ego, identity, love, purpose |
| 03 | Install the New Reality | Subconscious reprogramming, manifestation |
| 04 | Signal & Nurture Daily | Gratitude, coherence, daily practice |

---

## Project Structure

```
app/                  Next.js app router pages
components/
  layout/             Header, footer, navigation
  sections/           Page sections (hero, features, etc.)
  ui/                 Reusable UI components
public/               Static assets, images, icons
docs/                 Documentation
  APP_REFERENCE.md    Complete reference for all 20 app tools
```
